갤러그(Galaga) 게임을 참고하여 제작한 슈팅 게임입니다.

플레이어는 이동하며 총알을 발사해 적을 모두 소탕하는 것이 목표입니다.

---

# 플레이 방법

**플레이어 이동**: 키보드 방향 키 ( <, > )

**공격**: 키보드 (SPACE)

**클래식 모드 (START!로 시작)**

- 3개의 Stage로 이루어져 있으며, 마지막 Stage에서 보스가 나옵니다.
- 모든 Stage를 클리어하게 되면 시작 화면으로 돌아옵니다.

**무한 모드 (INFINITE MODE로 시작)**

- Stage가 무한하며, 각 Stage마다 난이도 별로 랜덤한 Wave가 생성됩니다.
- 적을 소탕할 때마다 점수가 증가하며, 최대한 많은 점수를 얻는 것이 목표입니다.
